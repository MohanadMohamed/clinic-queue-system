# Clinic Queue System

Real-time clinic queue management system built with React, Express and Socket.io.

## Features

- Reception can add patients
- Doctor can move to the next patient
- Queue screen shows current and waiting patients
- Real-time updates using Socket.io

## Tech Stack

Frontend:
- React
- React Router

Backend:
- Node.js
- Express
- Socket.io

## How to run

### Server

cd server
npm install
npm run dev

### Client

cd client
npm install
npm run dev
